# Python - Async Comprehension

This project covers asynchronous generators, async comprehensions, and type-hints for generators in Python.

## Learning Objectives

- How to write an asynchronous generator
- How to use async comprehensions
- How to type-annotate generators

## Requirements

- All files interpreted/compiled on Ubuntu 20.04 LTS using python3 (version 3.9)
- All files should end with a new line
- First line of all files: `#!/usr/bin/env python3`
- Code should use pycodestyle style (version 2.5.x)
- All files must be executable
- All modules and functions should have documentation
- All functions and coroutines must be type-annotated

## Tasks

0. **0-async_generator.py** - Async Generator
1. **1-async_comprehension.py** - Async Comprehensions
2. **2-measure_runtime.py** - Run time for four parallel comprehensions
